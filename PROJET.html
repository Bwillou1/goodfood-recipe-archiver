🥦 Goodfood Recipe Archiver

Récupère tes recettes Goodfood achetées et les compile en un seul PDF — piloté par une IA, sans rien installer.

🤖 Mode agent IA  ·  🔐 Connexion réelle  ·  📄 PDF final

💡Le problème que ça résout

Goodfood n'envoie plus les recettes sur papier. Elles sont stockées dans ton compte en ligne. Pour retrouver une recette, il faut se reconnecter au site, naviguer dans ses commandes, et ouvrir chaque plat un par un.

Ce projet automatise tout : à partir d'une capture d'écran de ta facture, il retrouve les recettes sur le site, les extrait, et produit un PDF propre par recette, puis les assemble en un seul fichier final.

Les 3 points techniques clés

🔐 Connexion réelle (pas de cookie)

Un agent IA part d'un environnement neuf, il ne peut pas réutiliser un cookie de ton navigateur. Le code remplit donc réellement le formulaire Goodfood avec ton email et ton mot de passe.

🧠 Correspondance intelligente

Le nom du plat sur la facture (ex. « Poulet au beurre ») est rapproché de la recette du site (ex. « Poulet au beurre à l'indienne ») grâce à un match flou (rapidfuzz).

📚 Assemblage PDF

Chaque recette devient un PDF (titre, ingrédients, étapes), puis tous les PDF sont fusionnés avec une page de garde en un fichier unique.

🧱L'architecture du projet

├── AGENTS.md          # ⭐ instructions lues par l'agent IA

├── src/

│   ├── ocr_receipt.py # lecture de la facture (OCR)
│   ├── finder.py      # recherche des recettes
│   ├── pdf_builder.py # 1 PDF par recette
│   ├── assembler.py   # fusion en PDF final
│   └── demo.py        # PDF d'exemple (sans compte)
└── data/
    ├── receipts/      # captures de facture
    ├── recipes/       # PDF individuels
    └── output/        # PDF final

🍴Comment forker le projet

« Forker » = copier le dépôt dans ton propre compte GitHub pour pouvoir le modifier librement, sans toucher à l'original.

Méthode A — Forker via le site GitHub (la plus simple, même sur iPhone)

1. Ouvre la page du dépôt sur GitHub.

2. Clique sur le bouton « Fork » en haut à droite.

3. Choisis ton compte comme destination, puis « Create fork ».

4. C'est fait 🎉 — tu as maintenant ta propre copie sous ton-pseudo/goodfood-recipe-archiver.

💡 Après le fork, n'oublie pas d'ajouter ton fichier .env (avec tes identifiants) — il est ignoré par Git, donc jamais partagé publiquement.

Méthode B — Cloner en local (si tu veux travailler sur un ordi)

$ git clone https://github.com/ton-pseudo/goodfood-recipe-archiver.git
$ cd goodfood-recipe-archiver
$ pip install -r requirements.txt
$ playwright install chromium
$ cp .env.example .env        # puis édite .env avec tes identifiants
$ python run.py

Méthode C — Depuis la ligne de commande (fork + clone)

GitHub n'a pas de commande native « fork », mais le CLI gh le fait très bien :

$ gh repo fork NOM_DU_REPO_ORIGINAL --clone

🤖L'utiliser avec une IA (depuis ton iPhone)

1. Ouvre Claude / Mistral / ChatGPT et colle l'URL de ton dépôt (après le fork).

# Exemple de message à envoyer à l'IA :
« Fais tourner le projet dans ce dépôt GitHub :
récupère mes recettes Goodfood et donne-moi le PDF final.
Voici la capture de ma facture : [image] »

2. L'IA lit automatiquement AGENTS.md (le mode d'emploi du projet).

3. Elle te demande une seule fois ton email + mot de passe Goodfood.

4. Elle installe tout, se connecte réellement, retrouve tes recettes et te rend Goodfood_recettes.pdf.

⚠️ Point important : pour une vraie connexion à ton compte, l'IA a besoin de tes identifiants. Ne les colle jamais dans un message public. Certains sites peuvent afficher un CAPTCHA — dans ce cas, l'agent te préviendra clairement.
